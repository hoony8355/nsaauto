# 제품/개발 명세 (v0.1)

## 1) 프로젝트 컨텍스트
- **목적:** 네이버 검색광고(파워링크/쇼핑검색) 하이어라키를 사용자 설정 기반으로 자동 생성
- **핵심 가치:** 퍼포먼스 마케터 운영 공수 절감, 세팅 오류 예방
- **대상 API:** 네이버 검색광고 NCC API

## 2) 하이어라키 생성 로직

### 캠페인 분기 기준
1. 제품군/카테고리
2. 기기(PC/Mobile)
3. 키워드 성격(Brand/General)

### 광고그룹 분기 기준
1. 기기/매체
2. 성별(남/여/모두)
3. 연령(10대~60대+) — 개별 그룹 분리 또는 타겟 포함/제외
4. 지역(전국/특정 지역)

### 생성 원칙
- 조합 가능한 기준을 선택형으로 제공
- 명명 규칙(Naming Convention)으로 고유성 보장
- API 실행 전 트리 Preview로 사용자 확인

## 3) 기술 요구사항

### 보안/인증
- 사용자로부터 `Access License`, `Secret Key`, `Customer ID` 입력
- 키는 서버 세션/메모리 기반 단기 보관 (영구 저장 금지)
- 민감정보 로깅 금지 및 마스킹

### 타겟팅
- `AdGroup.targets`의 `age`, `gender` 필드를 사용
- 예시: `AGE_20`, `AGE_30` 코드 매핑
- 포함/제외 정책을 명시적으로 분리해 구성

### 실행 전 검증
- 생성될 구조를 Tree UI로 시각화
- 총 캠페인/광고그룹/키워드 생성 수량 사전 계산
- 컨펌 후 실행 (Dry-run → Execute)

## 4) 템플릿 정의

### 4-1. Brand/General 분리형
- 브랜드 키워드와 일반 키워드를 캠페인 단위로 분리
- 예산/입찰/ROAS를 독립 관리

### 4-2. Device-Specific형
- PC/Mobile 캠페인 완전 분리
- 기기별 예산과 성과 최적화

### 4-3. Shopping-Focus형
- 쇼핑검색 전용
- 상품별 1:1 광고그룹 또는 카테고리 단위 제외키워드 통합 관리

## 5) 사용자 플로우
1. API 인증 정보 입력
2. 매체(파워링크/쇼핑검색) 및 템플릿 선택
3. 분기 기준/명명 규칙 설정
4. Preview 트리 및 생성 건수 확인
5. Execute 및 결과 리포트 확인

## 6) 권장 시스템 구조 (React + Node.js)
- **Frontend (React):** 설정 폼, Tree Preview, 실행 결과 대시보드
- **Backend (Node.js/Express):** 템플릿 엔진, NCC API 클라이언트, 검증 로직
- **DB (PostgreSQL):** 워크스페이스, 템플릿, 실행 이력, 생성 결과 저장
- **Queue (선택):** 대량 생성 시 비동기 처리 및 재시도

## 7) API 호출 안전장치
- 요청 속도 제한(rate limit) 보호
- 멱등 키(idempotency key)로 중복 생성 방지
- 부분 실패 시 롤백 또는 실패 항목 재시도 전략

## 8) MVP 범위
- 템플릿 3종 제공
- 연령/성별 타겟팅 포함/제외
- Preview + Execute + 결과 리포트
- 실행 히스토리 및 에러 사유 조회
